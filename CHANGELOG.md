# Changelog

## Foundation 1.2 — Parables catalogue
- Added a searchable, theme-filterable catalogue of 33 parables and parable-like illustrations of Jesus.
- Added detail panels with summaries, central teachings and Scripture references.
- Added direct passage navigation from catalogue references into the existing offline Bible Reader.
- Added responsive catalogue styling for desktop, tablet and mobile layouts.
- Kept all four translation data files separate and unchanged.
- Kept all runtime assets local; no external network requests or server required.

## Foundation 1.1 — WEB-C
- Added the separate WEB-C translation dataset.
- Added the day/night Scripture reading appearance toggle.
- Preserved KJV, WEB and Webster translation data.
