The source copyright information identifies the World English Bible text as public domain. The name “World English Bible” is a trademark of eBible.org and should be reserved for faithful copies of the translation.

Conversion notes
- The source USFM was converted into the local JavaScript data structure used by this application.
- The translation text was retained as plain verse text. USFM formatting, Strong’s word identifiers, footnotes and cross-references are not displayed in this reader build.
- Verse positions that contain only a source footnote explaining that the wording is omitted from the main text are retained with the explicit placeholder: “[Not included in the main text of this edition.]”
- Esther (Greek) and Daniel (Greek) retain the source edition’s distinct book labels.
- WEB-C remains a separate edition from the 66-book World English Bible (WEB). No WEB verses were copied into WEB-C.
